# Valet for Windows

Valet automatically organizes files using folder rules.

[Download the latest Valet installer](https://github.com/Elixir-Piloting/Valet-releases/releases/latest/download/Valet-x64.exe)

The link always points to the latest published Windows release. It becomes available after the first signed installer is published. Release notes and installer signatures accompany each release. The `update.json` manifest is consumed by installed copies of Valet.
